# Generic dry-air atmosphere source packet

The standard dry-air profile reads `src/sim/data/atmosphere/ussa-1976.v1.ts`.
It uses the lower-atmosphere equations of [U.S. Standard Atmosphere, 1976](https://ntrs.nasa.gov/citations/19770009539), NOAA/NASA/USAF, NASA-TM-X-74335 / NOAA-S/T-76-1562, published October 1, 1976. Source ID: `noaa-nasa-usaf-ussa-1976-lower-atmosphere`. Data group: `weather/atmosphere`; confidence: `derived-from-source`; quality: `public-reference`.

NASA NTRS identifies this report as public distribution and “Work of the US Government, Public Use Permitted” (checked October 8, 2026). This repository contains numeric facts, citations and independently implemented equations; the PDF is not embedded. Reviewed PDF SHA-256: `23eb6b68346d4abc6071fc598872d51c40cf8c613d1a5d1006c6261bcd09dcea`.

The input is geometric altitude in feet. Convert feet to meters exactly with 0.3048, then geometric Z to geopotential H using Eq.18, printed p.8: H = r0 Z / (r0 + Z). The source defines r0 = 6,356,766 m. Using geometric height directly in the geopotential lapse equations produced pressure and temperature errors, particularly near the tropopause.

Constants come from Tables 2/4, printed pp.2–4, and M0 on p.9: sea-level T = 288.15 K, P = 101,325 Pa, gravity = 9.80665 m/s², universal gas constant = 8,314.32 J/(kmol·K), dry-air molar mass = 28.9644 kg/kmol and gamma = 1.4. The specific gas constant is their ratio. Layers start at geopotential 0, 11,000 and 20,000 m with lapse rates −0.0065, 0 and +0.001 K/m. Boundary temperatures and pressures are derived recursively using Eq.33a/b, p.12. Density uses Eq.42, p.15; sound speed uses Eq.50, p.18; viscosity uses Eq.51, p.19. Eq.51 explicitly gives S = 110.4 K and beta = 1.458×10⁻⁶; the rounded 110 K shown in Table 2 does not replace that equation value.

Holdout bounds are one last printed unit for each quantity, including the limited precision of the five-significant-figure tables. For example the 11-km pressure row is 2.2699×10² hPa; the equations give about 226.9996 hPa. This is not a claim that every published entry rounds to the nearest half unit. Bounds are fixed before implementing the correction; none of the source formulas is fitted to those rows. Tests also check finite positive outputs, monotonic pressure and continuity at the actual geopotential boundaries. A separate module-substitution test proves both standard and weather consumers read the versioned constants.

The reference domain is dry homogeneous standard air from geometric −1,000 m through geopotential 32,000 m (about geometric 32,162 m). The remaining USSA layers and molecular-mass variation are not implemented. Continuing the last lapse above this range or below the lower limit is an unsupported engineering extrapolation.
